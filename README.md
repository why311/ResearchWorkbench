# 研舟 · ResearchWorkbench

面向学生的科研工作台，围绕论文阅读、证据定位、实验复现与成果整理构建研究流程。

## 当前公开版本

当前围绕传智杯AI大模型创新应用挑战赛推进。

项目与文献管理：React页面、FastAPI服务、SQLite项目存储，支持PDF、UTF-8文本和Markdown导入、分页原文阅读、逐段批注、项目阅读待办、原文检索定位、阅读笔记导出及原文件下载。
已有本地实现按可运行阶段整理后逐步公开；本仓库当前版本尚不包含完整科研功能。提交与验证使用实际时间记录。

## 运行

使用Python 3.12与Node.js 20或更新版本。

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
npm install
npm run build
.venv/Scripts/python.exe -m uvicorn backend.app:app --host 127.0.0.1 --port 8787
```

打开 http://127.0.0.1:8787 。新建项目并填写研究问题，在“项目文献”中导入全文，选择资料后按页阅读。每次显示最多100段，可以继续翻页段；下载保留原文件。

单篇最大20MB、300页、100万字符。普通导入提取PDF可选文字；“PDF与OCR”入口支持后台结构化解析和扫描页OCR；支持逐段标记重点/待弄清/已理解、保存或编辑个人批注，并导出带页码及原文的Markdown笔记。单篇最多200段批注，每段4000字。模型精读仅支持下述单页草稿，双语阅读支持页段翻译；尚未包含语义嵌入、实验执行或完整成果导出。数据保存在本地data目录，未配置公网账号和访问控制。

## 阅读待办

项目中的“待弄清”批注集中展示，可按文献、状态及笔记或篇名筛选。每组最多50条，支持修改笔记、标为已理解及回到具体原文页段。修改不会改写原文；原文编辑区与待办更新保持同步。

## 原文检索

在当前项目中输入问题或关键词，可搜索全部资料或指定文献。字符与词项TF-IDF结果融合，展示原文和页段；点击可回到对应位置，支持单页100段以后的内容和JSON导出。结果是检索候选，不是生成的研究结论。最多处理5000段、200万字符，超过时明确要求缩小到单篇，不静默截断。


## 论文精读笔记

选择精读文献，按问题、机制、公式、实验、复现诊断和局限整理笔记，区分原文有据、推断、猜测和本次材料未找到。原文有据的记录必须关联本篇真实页段；支持编辑、分页选择来源、回看原文和导出带来源的Markdown。每篇最多40条笔记，达到上限仍可修改已有内容。

支持人工整理与单页模型草稿；不包含公式排版或实验联动；来源存在不代表作者解释正确。阅读框架参考paper-xray，许可见[第三方说明](THIRD_PARTY_NOTICES.md)。


## 模型辅助精读

在服务端设置`.env.example`列出的`RESEARCH_MODEL_URL`、`RESEARCH_MODEL_NAME`、`RESEARCH_MODEL_KEY`环境变量，再启动服务；不自动读取.env文件。地址为兼容Chat Completions的基础地址，调用时追加`/chat/completions`。密钥仅供服务端使用，不在浏览器填写或返回。

选择文献和原文页码，点击“生成本页精读草稿”。本轮只发送所选页的原文，每页最多24000字符，最多追加8条草稿，每篇总计40条。人工未保存内容或编辑中不会启动生成。已有笔记保持原样，生成结果仍可人工修改、回看与导出。

原文有据条目必须提供本页真实片段及逐字引文，来源错误的条目跳过；全部无效或调用失败时不改动笔记。引文存在不代表解释正确。本阶段为单页生成，不冒充全文精读、支持逐Token输出或研究质量评测。


## 双语对照阅读

选择文献、中文或英文目标语言及页码，按原文段落对照阅读，支持手动编辑、保存核对状态和导出ZIP（Markdown、离线HTML、来源JSON）。译文独立存储，不改写原文，也不作为原文检索依据。

“翻译本页段”只将当前最多40段发送给已配置模型；原文材料超过20000字符时明确拒绝，不截断。仅接受原ID和完整原文逐字对应的译文；已有记录及模型请求期间的人工保存优先保留。字段和原文对应核对不证明翻译正确，数字、公式和术语仍需作者核对。单段译文最多8000字符。本公开阶段不包含后台全文翻译、悬停查词或同步滚动。


## 文献引用管理

选择实际参考文献页（单次最多30页、20万字符），提取可定位的DOI/arXiv标识。候选按标识去重；支持回看原文、编辑名称、人工确认引用、关联项目内其他全文、筛选已确认记录及导出JSON。重复提取保留人工确认与关联；跨项目关联和关联来源文献自身会被拒绝。

原文中出现标识不自动证明引用关系；当前不猜测无标识题名，也不自动确认引用。单次最多300个标识，每篇最多1000条记录。导出及页面保留项目内范围，不提供全网被引次数或质量评分；关系图与PageRank等分析留待后续阶段。


## 文献处理与发现（四批计划第1批）

“文献处理与发现”提供结构化PDF后台解析、扫描页本机OCR、任务进度、停止/继续、页面结构候选查看。结构化入口支持32MB、2000页；普通导入保持原有限制。资源与队列限制、进程停止及原件保存保留。现有阅读、批注、双语与引用工具可读取已完成的结构化页面；原文片段标识不随译文或笔记变化。

多源题录检索支持Crossref、arXiv与PubMed；arXiv主题追踪可手动刷新，自动刷新默认关闭且仅在服务运行时生效。题录检索会发送检索词；题录及摘要不自动成为项目全文依据。支持反馈排序、GitHub链接优先、arXiv官方PDF导入；批量下载支持最多20条，匹配歧义需手动选择，仅使用arXiv和NLM PMC开放全文，保留来源与许可，失败可逐条重试。

引用分析根据本项目人工确认并关联全文的连接计算入向/出向引用、PageRank、弱连通分量和孤立节点，可导出Mermaid关系图。结果只反映本地项目的连接范围，不代表全网被引统计或论文质量。当前页面提供分析表与连接列表，Mermaid可用于绘图。

公式、表格、题名及OCR均需结合原件核对，不保证复杂版面准确还原。本批保留已有安全限制；本轮原有20项测试、新增10项检查及前端构建通过，包含实际后台PDF与本机OCR执行，未新增浏览器视觉核对或学术质量评测。


## 研究与写作（四批计划第2批）

- **语义检索**支持中文问题检索英文资料，并可与关键词融合。首次准备需下载本地模型。选定全文后分别建立索引，原文和问题在本机计算。检索结果可回到对应原文页段。
- **证据比较与研究任务**支持逐篇核对和自定义比较项。研究任务保留实际工具调用、原文来源和待核对条件，可停止并导出JSON或比较表CSV。可将比较结果保存为待验证设想并导出。配置服务端模型后可启用限步工具调用，未配置时运行本地流程。
- **综述与演进**可按所选原文生成综述草稿、核对后续文献回应、记录人工时间线并导出研究流程图。启用生成时，检索到的原文会发送给已配置的模型服务。逐字核对用于验证引文位置，语义支持仍由作者确认。
- **开题与草稿**可在本机根据所选全文生成引用开题框架、查阅展望段落。综述和开题先保存为可编辑的Markdown草稿，导出包含文献名、页码、片段编号和原文。

本批使用既有服务端环境变量配置模型。实验运行、数据分析和论文成稿导出分别安排在后续两批。


## 实验与分析（四批计划第3批）

在「实验与分析」中可运行内置 Iris 分类，导入公开 GitHub 仓库或 ZIP，选择 Python 入口及参数。外部代码通过 Docker 隔离运行，仓库只读，运行时禁网，限制 CPU、内存、进程数和运行时间。先启动 Docker，再在界面准备隔离环境。结果、参数、日志及复跑材料均可导出。

批量对照为每个方案使用同一组种子，逐次运行并保存结果。可关联待验证的研究设想。配对统计仅纳入同种子且双方成功、存在指定指标的运行。

数据分析支持 CSV、TSV、XLSX 导入，提供缺失值处理、去重、缩放、数值筛选、描述统计、分组比较、相关分析和图表。可导入项目内的 CSV/TSV 运行产物，导出包保留处理参数、审计计数和复跑脚本。
