# 功能进度 · 2026-10-21

## 本轮完成

| 功能 | 实际行为 | 边界 |
| --- | --- | --- |
| 双语对照阅读 | 按页段加载原文与中文/英文译文，人工编辑、核对状态、模型补充缺失译文、导出双语包 | 原文对应检查不能验证译文语义；尚未连接真实模型供应商做翻译质量评价 |
| 项目内引用关系 | 参考页标识提取、重复候选去重、原文核对、关联全文、方向图、入向引用、JSON导出 | 只提取DOI/arXiv；无标识题名不自动猜测；不提供全网被引次数 |

这两项直接复用原文片段和项目全文。译文保持独立，证据检索仍引用原文；候选出现不自动形成已确认的引用关系。没有增加hash、冻结contract、baseline或gate。

## 已完成的主流程

项目与研究问题、文献库、后台PDF/OCR、按页原文、论文精读与批注、逐篇证据比较、有限工具研究任务、研究设想、Iris多种子对照、Docker外部仓库单次运行、CSV/XLSX分析、指标绑定与成果同步、导出与本地Git记录。

## 尚未完成，建议顺序

1. **跨语言语义检索**：当前只有字符和词项两路稀疏检索及少量关键词别名；需真正接入嵌入模型，并用有标注的原文问题衡量召回。
2. **外部仓库批量对照实验**：当前多种子/单因素对照只支持Iris；需为外部入口提供明确参数映射、共享种子和可比指标，继续保留隔离与停止能力。
3. **真实模型与学生使用验证**：当前模型响应结构、原文对应和越界过滤使用受控返回检查；需要实际服务和学生任务验证翻译、提取、工具选择的质量与耗时。不能凭自动测试声称提高科研质量。
4. **公式、复杂图表与Word成果**：已有公式排版与候选提示、线框表格、Markdown成果；尚未可靠还原公式/扫描图表，尚无Word模板导出。

公网账号、任意自动安装依赖、自动改代码和无人值守生成论文不属于当前已实现范围。
