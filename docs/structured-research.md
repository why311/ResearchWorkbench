# 结构化文献与研究任务阶段

本阶段把资料导入、逐篇查证和研究设想连接起来。解析任务逐页存储，比较结果保留具体原文，待验证设想不附加虚构实验结果。

## 如何体验

1. 新建项目，在研读的“文档结构”导入PDF，查看解析状态、原页与本页文字。原生PDF和扫描PDF均可导入。
2. 在“证据比较”选择1—8篇文献，每行填写一个比较项，开始比较。展开单元格来源并点击回看原文。
3. 在“研究任务”填写明确目标，观察工具记录。无模型时为本地固定流程；兼容服务支持工具调用后可启用模型选择工具。
4. 导出比较表和工具记录，保存为待验证设想，到总览补充可检验预期并安排已有的对照实验。

## 验证范围

自动检查使用临时数据库，不覆盖用户资料。真实执行541页合成PDF解析、末页检索与渲染、扫描页OCR、表格识别、内容版本提示、停止与继续、跨项目访问限制。研究任务检查逐篇来源归属、伪造引文过滤、真实工具反馈传递、导出、停止及重复保存设想。

合成资料仅用于验证程序，不作为论文复现成绩。工具调用协议采用受控响应检查，未连接真实模型供应商，尚不能据此报告模型的提取质量或自主规划质量。Docker检查取决于本机引擎可用性。

浏览器实际操作验证另建“流程验证 · 结构化文献与证据比较”项目，使用原生与纯扫描测试文件。扫描识别可能丢失空格，不能把识别置信度当作学术结论可信度。
