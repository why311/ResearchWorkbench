## 本轮补全

- 图谱仅使用已确认且连接到本地文献的引用，去掉重复边和自环。PageRank表示项目内关系，不能代表论文质量或全领域影响力。
- Future Work提取保留原话、文献、页段；候选不等于新颖选题，也不自动宣称尚未解决。
- 研究框架写入已有成果模块，引用来自所选文献的摘要或首个可用片段。研究结果、方法及贡献保留待填写，不自动编造。
- arXiv订阅默认关闭自动刷新。开启后只在本地服务运行时检查，间隔6—168小时；请求串行、至少间隔3秒，记录真实错误。支持关键词和arXiv编号，反馈影响本地排序，GitHub优先仅按题录中的链接排序，不代表已验证仓库可运行。
- 导入复用原有PDF解析队列和资源限制。arXiv题录保存到导入记录中，解析候选标题另存，避免首页许可文字覆盖正确题名。

接口依据：[arXiv API User’s Manual](https://info.arxiv.org/help/api/user-manual.html)。实际编号查询和PDF下载成功；关键词请求遇到429及超时，已如实显示，未用演示数据替代。
