# 传智杯赛道要求对照（2026-11-01）

依据《传智杯大赛-赛道详情2.pdf》第2—6页整理。本轮补齐下表中的软件功能并接入真实DeepSeek服务，功能、质量评测和参赛交付物分别记录。

| 要求 | 已实现与操作入口 | 验证范围与限制 |
| --- | --- | --- |
| 导入、结构化、版本 | 后台PDF/OCR、原件与页段；文献管理→文献整理支持逐段差异、并存与优先版本 | 541页合成PDF完整解析，末页标记核对成功，约9.9秒；不是复杂扫描件准确率评测。旧引文和批注保留 |
| 问答、多文献推理 | 原文检索、逐字引文校验、多文献比较、有限工具研究任务 | 真实模型问答跑通；逐字匹配不保证解释正确，还需标注问题集评测 |
| 阅读与翻译 | 独立双栏及同步滚动、划词翻译、可选悬停查词、全文缺失译文队列、人工核对；正文编号与书目双向定位 | 真实模型完成受控材料3段翻译，42和0.80保留；已有及并发人工译文保留。编号主要支持方括号数字 |
| 公式与图表 | 文献整理→公式与图表解读：真实原页图片与文字，单独保存LaTeX、表格、图示、作者单位及不确定项；表格CSV | Attention论文第4页真实图像请求识别注意力公式与图2；模型笔记不替换OCR或原文，精确数值与模糊符号仍需核对 |
| 文献发现 | Crossref、arXiv、PubMed题录；arXiv订阅、反馈、PDF下载与后台导入 | 三源真实请求验证；Crossref及PubMed各12条，arXiv论文下载成功。仍可能限流超时，题录不是全文证据 |
| 引用与仓库判断 | 编号回引、无正文位置及密集列举复查提示；仓库README、依赖、入口、测试、许可、CI和实际运行记录 | 提示不自动认定敷衍引用；文件、星标和同种子参数不能证明成功复现 |
| 图谱、综述与方向 | 项目内图谱、PageRank、连通分量；来源综述、语义支持检查、问题证据时间线与最新作者判断筛选、SVG/Mermaid框架 | 实际综述2条被接纳，支持检查2条返回支持，仅是单次流程结果；不能证明全领域已解决或选题新颖 |
| 写作与书目 | 可编辑成果、原文引用、Markdown/Word；题录、DOI补齐、GB/T和APA基础样式、BibTeX；学校模板导出 | 缺失字段明确提示；不是完整CSL样式库。模板使用用户原文件的版式样式，不自动完成封面、摘要、目录和整篇论文 |
| 数据图表 | 原有统计、分组、Pearson；折线、二维及三维分组雷达、实际数据图注、独立复跑 | 数值及PNG验证；雷达归一化，三维Z轴为组序号，不能理解为第三个测量变量或显著性 |
| 多用户 | 可选账号验证、项目归属、维护者设置权限；请求来源和Docker安全限制保留 | 两账号隔离测试通过；当前仍在本机运行，未部署公开演示 |

- 完整回归63项通过，包含真实Docker运行及隔离复跑；前端生产构建通过。

- 用户学校.doc模板转为本机私有.docx，原文件未更改。3页导出样本已逐页渲染查看。原文抽取公式的断行按来源保留，公式识别另存在页面解读中，不悄悄改写引文。
